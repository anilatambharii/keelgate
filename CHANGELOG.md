# Changelog

All notable changes to Keelgate are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/), and the project follows
[Semantic Versioning](https://semver.org/) as described in
[docs/versioning.md](docs/versioning.md).

Entries after 0.1.0 are generated by [release-please](https://github.com/googleapis/release-please)
from Conventional Commits when a release pull request is merged.

## 0.1.0 (2026-10-07)

The first publication, and a snapshot rather than a contract. It contains the safety core (tools,
capabilities, policy, audit, approvals), the durable loop, context, memory, the LLM client layer,
the MCP, LangGraph, OpenAI Agents, Claude Agent SDK, A2A and Temporal adapters, and the testing
kit. It has no telemetry, replay or eval framework, and every module was importable by its
internal path.

Nothing in 0.1.0 carried a stability promise beyond what `docs/integration-contract.md` said at
the time. 0.2.0 is the first release with an enforced public API; see the migration guide
([docs/migrating-to-0.2.md](docs/migrating-to-0.2.md)).
